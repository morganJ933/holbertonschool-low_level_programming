# C - Hello, World

## Description

This project introduces the basics of C programming at Holberton School.
The `1-compiler` script compiles a C source file without linking.
The 2-assembler script generates assembly code from a C source file.
The 3-name script compiles a C source file and creates an executable named cisfun.
The 4-puts.c program prints a specific message using the puts function.
The 5-printf.c program prints a specific message using the printf function.
