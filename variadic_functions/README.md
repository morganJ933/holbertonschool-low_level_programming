# Task of the project

0. Beauty is variable, ugliness is constant Created a variadic function that returns the sum of all its integer arguments using va_start, va_arg, and va_end.
1. To be is to be the value of a variable Created a variadic function that prints integers separated by a given string, handling NULL separators and ending with a new line.
2. One woman's constant is another woman's variable Created a variadic function that prints strings separated by a given separator, replaces NULL strings with (nil), and ends with a new line.
3. Print anything Created a variadic function that prints characters, integers, floating-point numbers, and strings based on a format string, handling NULL strings and ignoring unknown format characters.
