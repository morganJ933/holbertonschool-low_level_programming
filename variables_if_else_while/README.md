# C - Variables, if, else, while

This project introduces variables, conditional statements, and loops in C.

## Task of the project.

The 0-positive_or_negative.c  program generates a random integer and prints whether it is positive, negative, or zero.
The 1-last_digit.c program generates a random integer and prints its last digit.
The 2-print_alphabet.c program prints the lowercase alphabet from a to z, followed by a newline.
The 3-print_alphabets.c program prints the lowercase alphabet followed by the uppercase alphabet.
The 4-print_alphabt.c program prints the lowercase alphabet, excluding the letters e and q.
The 5-print_numbers.c program prints all single digit numbers of base 10, from 0 to 9, followed by a newline.
The 6-print_numberz.c program prints all single digit numbers of base 10, from 0 to 9, followed by a newline.
The 7-print_tebahpla.c program prints the lowercase alphabet in reverse order, from z to a, followed by a newline.
