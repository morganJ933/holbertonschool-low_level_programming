# Functions and Nested Loops

This project introduces functions, function prototypes, header files, variable scope, and nested loops in C.

## Task of the project.

The `0-putchar.c` program prints `_putchar`, followed by a newline.
The 1-alphabet.c file defines the print_alphabet function, which prints the lowercase alphabet followed by a newline.
The 2-print_alphabet_x10.c file defines the print_alphabet_x10 function, which prints the lowercase alphabet 10 times, each followed by a newline.
