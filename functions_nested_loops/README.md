# Functions and Nested Loops

This project introduces functions, function prototypes, header files, variable scope, and nested loops in C.

## Task of the project.

The `0-putchar.c` program prints `_putchar`, followed by a newline.
The 1-alphabet.c file defines the print_alphabet function, which prints the lowercase alphabet followed by a newline.
The 2-print_alphabet_x10.c file defines the print_alphabet_x10 function, which prints the lowercase alphabet 10 times, each followed by a newline.
The 3-islower.c file defines the _islower function, which checks whether a character is lowercase.
The 4-isalpha.c file defines the _isalpha function, which checks whether a character is alphabetic.
The 5-sign.c file defines the print_sign function, which prints the sign of an integer.
The 6-abs.c file defines the _abs function, which computes the absolute value of an integer.
The 7-print_last_digit.c file defines the print_last_digit function, which prints and returns the last digit of an integer.
The 8-24_hours.c file defines the jack_bauer function, which prints every minute of a day from 00:00 to 23:59.
The 9-times_table.c file defines the times_table function, which prints the multiplication table from 0 to 9.
The 10-add.c file defines the add function, which adds two integers and returns their sum.
