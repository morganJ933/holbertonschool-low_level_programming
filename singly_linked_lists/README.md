# Singly linked lists

0. Print list - Created a function that prints all elements of a singly linked list and returns the number of nodes.
1. List length - Created a function that returns the number of nodes in a singly linked list.
2. Add node - Created a function that adds a new node at the beginning of a singly linked list.
3. Add node at the end - Created a function that adds a new node at the end of a singly linked list.
4. Free list - Created a function that frees all nodes and their strings in a singly linked list.
