# C - More malloc, free

## Task of the project .

0. Created a function that allocates memory using malloc and terminates the program with exit status 98 if allocation fails.
1. Created a function that concatenates two strings using a specified number of bytes from the second string.
2. _calloc Created a function that allocates memory for an array using malloc and initializes all bytes to zero.
3. array_range Created a function that dynamically allocates an array of integers containing all values from min to max.
